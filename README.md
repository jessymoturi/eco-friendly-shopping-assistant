# Eco-Friendly Shopping Assistant (EcoCart)

## About the Project
EcoCart is a web-based application that helps users make environmentally responsible shopping decisions. It allows users to explore products, check eco-friendly ratings, compare products, and save their favorite products to a wishlist.

## Technologies Used
- React.js
- Vite
- Node.js
- Express.js
- SQLite
- JavaScript
- CSS

## Features
- Product catalogue
- Product search
- Category filtering
- Eco-rating filtering (A–F)
- Price filtering
- Product comparison
- Wishlist
- Missing eco-data identification
- Responsive design

## How to Run
1. Download or clone the repository.
2. Install Node.js.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run `npm run install:all`.
6. Run `npm run dev`.
7. Open `http://localhost:5173` in your browser.

## Project Structure
- `frontend` – User interface and product display
- `backend` – Server and API functionality
- `README.md` – Project documentation

## Note
The eco-ratings used in this demonstration are sample ratings for educational purposes and are not certified environmental ratings.
